# Redis 运维语料 v1 人工审核记录

审核日期：2026-08-15  
语料：`redis-ops-7.4-v1`  
输入：39 篇官方文档  
抽样：`data/processed/review-sample.jsonl` 固定均匀抽取 20 个 chunk

## 审核维度

- 正文能否独立理解；
- `title`、`section_path` 与正文是否一致；
- 命令占位符、代码块是否完整；
- 是否残留 Hugo、HTML、Redis 8、Cloud 或 Software 噪声；
- `source_path`、`source_url` 是否可追溯；
- 内容是否符合 Redis 运维诊断知识库定位。

## 审核发现与处理

1. `<key>`、`<value>`、`<master-name>` 被宽泛 HTML 规则误删。已改为仅移除已知展示标签，并增加回归测试；
2. Hugo RESP 标签展开后可能留下相邻重复块。已增加相邻块去重规则和测试；
3. Redis Software/Cloud 推广段落可能出现在普通章节内。已增加内容块过滤；
4. Cluster CRC16 ANSI C 实现内容正确但不服务运维诊断，已作为范围决策排除；
5. 短命令参数片段虽不足 25 个近似 token，但结合标题和章节仍有明确语义，暂时保留；
6. 完整命令输出可能超过 450 个近似 token。当前保留整体，并在统计中显式列出，避免破坏示例结构。

## 最终结果

- 39 篇文档全部成功解析；
- 420 个 chunk；
- 删除 16 个 Redis 8 专属内容块；
- 删除 21 个产品兼容性章节和 5 个产品推广块；
- 删除 1 个无关源码附录；
- 20 个抽样覆盖命令、持久化、复制、延迟、ACL、Sentinel 与 Cluster；
- 解析、清洗、可追溯性与评测引用校验均有自动化测试。

结论：通过 P0-1 第一版语料验收，可进入 BM25 检索基线；chunk 长度仍需在后续固定评测上做参数实验。
