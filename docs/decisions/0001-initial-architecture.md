# ADR-0001：首期采用模块化单体加独立 AI 服务

## 状态

已接受。

## 决策

- Java Spring Boot 作为业务规则和权限的唯一执行入口。
- Python FastAPI 负责文档处理、检索、生成、Agent 编排和评测。
- 两个服务通过 HTTP 接口通信。
- 首期不拆微服务，不引入 Kubernetes。

## 原因

Java 便于深入练习业务后端；Python 生态适合 RAG 和模型调用。两个服务的边界能够体现 AI 不能绕过业务权限，同时避免无意义的微服务复杂度。

## 限制

HTTP 调用增加超时和部分失败场景，后续必须加入超时、错误映射、请求 ID 和必要的重试/降级。
