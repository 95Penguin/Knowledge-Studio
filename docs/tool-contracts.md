# Agent 工具契约

## search_knowledge

- 输入：`query`、`top_k`
- 输出：带 `chunk_id`、文档、章节、分数和片段的结果
- 权限：登录用户可用
- 副作用：无

## query_device

- 输入：`device_id`
- 输出：脱敏设备状态
- 权限：设备必须属于当前用户；执行前展示授权
- 副作用：无

## create_ticket

- 输入：`idempotency_key`、标题、描述、设备 ID、优先级
- 输出：工单 ID 与状态
- 权限：登录用户只能为自己的设备创建；必须明确确认
- 副作用：创建业务数据并写入审计日志

## transfer_to_human

- 输入：会话 ID、原因、摘要
- 输出：转人工状态
- 权限：登录用户可用
- 副作用：生成待人工处理记录或工单草稿

## 通用约束

- 模型输出只代表调用意图，不代表已获授权。
- Java 服务必须重新校验身份、资源归属、参数和业务状态。
- 每次调用记录 request ID、工具、脱敏参数、结果、耗时和错误。
- 工具超时、非法参数和未知工具必须安全失败。
